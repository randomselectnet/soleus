# Soleus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Android native saatlik ofis egzersiz reminder uygulaması (11 hareket + streak takibi).

**Architecture:** Single-Activity Jetpack Compose, MVVM + Clean, manuel DI, Room + WorkManager, offline-first.

**Tech Stack:** Kotlin, Jetpack Compose BOM, Navigation-Compose, Room, WorkManager, Lottie-Compose, JUnit4

**Spec:** `docs/superpowers/specs/2026-09-08-soleus-design.md`

## Global Constraints

- Dil Türkçe, tüm kullanıcı metinleri TR olacak.
- Renkler: kağıt #FAF6EF, mürekkep #1A1E1B, aksan #FF5C1A; Inter/Roboto/Space Grotesk font yok.
- Min dokunma 44dp, offline-first, gömülü JSON içerik.

```kotlin
package com.soleus.office.domain
fun dueExercise(exercises: List<String>, completed: List<String>): String {
    val done = completed.toSet()
    return exercises.firstOrNull { it !in done } ?: exercises.first()
}
fun calcStreak(days: Set<String>, today: String): Int {
    var c = 0; var d = java.time.LocalDate.parse(today)
    while (d.toString() in days) { c++; d = d.minusDays(1) }
    return c
}
fun shouldRemind(nowMin: Int, start: Int, end: Int) = nowMin in start until end
```
